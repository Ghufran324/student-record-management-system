# Student Record Management System - C++ Project

A console-based C++ application designed to manage student records efficiently. This project demonstrates Object-Oriented Programming (OOP) principles, file handling, and structured data management along with complete project documentation.

## 📁 Repository Contents
* `Student Record Management System.cpp` - C++ source code.
* `Student Record Management System Project Report.pdf` - Detailed project report and documentation.

## 🛠 Concepts & Technologies
* **Language:** C++
* **Core Concepts:** Object-Oriented Programming (OOP), Classes & Objects, File I/O, Data Structures, Console UI.

```bash
# 1. Clone this repository
git clone [https://github.com/Ghufran324/student-record-management-system.git](https://github.com/Ghufran324/student-record-management-system.git)
